# Synthetic teaching data

The J–V table in this directory is generated by `scripts/make_demo_data.py` from the forward model
and a deterministic noise model. It is provided for hardware-free smoke tests,
class demonstrations, and regression checks only; it is not a measurement from
Cell #3 or Cell #4 and must not be used as experimental evidence.

Regenerate it from the project root with:

```bash
python scripts/make_demo_data.py
```

The `full`, `calibration`, and `synthetic` profiles of `scripts/run_all.sh` also
regenerate this table before using it, so it remains synchronized with `config.py`.
The default output is `iv.csv`, and synthetic outputs are deliberately restricted to
this directory. EQE is calculated directly by `scripts/plot_eqe.py`;
there is no bundled synthetic EQE table that could be mistaken for a measurement.
