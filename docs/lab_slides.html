Device orientation

Read the p⁺-on-n Cell from Front to Rear

  • Light enters through the shallow p⁺ emitter at x = 0
  • The depletion region extends around the 0.5 µm junction, mostly into the lower-doped n base
  • Electrons are minority carriers in p⁺; holes are minority carriers in the n base
Direction check: in the depletion region, the built-in field points from n to p (−x): holes drift toward the front and electrons toward the rear. Diffusion also matters in the quasi-neutral regions.
Before solving: sketch the sign of net doping and electric field.

Physics → numerics

Governing Equations Solved by DEVSIM

Electrostatics

∇·(ε∇ψ) = −q(p − n + ND − NA)

Charge sets potential, band bending and electric field.

Carrier conservation

∇·Jn = q(R − G),   ∇·Jp = −q(R − G)

Generation, recombination and current must balance.

Jn = qµn(nE + Vt∇n),    Jp = qµp(pE − Vt∇p)

Task 2 · Terminal non-idealities

Rs and Rsh Distort Different J–V Regions

python scripts/plot_resistance.py
  • Rs: rounds the high-current knee and mainly lowers FF
  • Rsh: tilts the curve near short circuit and lowers Voc/FF
  • Both are effective terminal post-processing terms here—not spatial DEVSIM regions
Diagnosis: does the measured voltage range contain the region needed to infer Rs?

Task 2 · Spectral response

EQE Locates Wavelength-Dependent Losses

python scripts/plot_eqe.py
  • EQE = collected electrons per incident photon
  • Blue loss probes front-region/emitter collection
  • Near-IR loss probes weak absorption and base/rear collection
  • Jsc = q∫EQE(λ)Φ(λ)dλ
Cross-check: integrate the modeled EQE and compare its Jsc with the all-bin J–V result.
Data boundary: no measured EQE is bundled or required. Add an overlay only when a real spectral measurement is available.

Task 3 · Before fitting

Sensitivity: Does the Observable Respond?

python scripts/plot_sweep.py --param hole_lifetime --start 1e-6 --stop 1e-4 --n 5
  • τp is region-wide; the response is dominated by minority holes in the n base
  • Longer lifetime improves collection until other losses dominate
  • Jsc responds strongly; Voc changes more weakly
Calibration rule: if an observable barely moves, it cannot reliably identify that parameter.

Task 5 · Trust the parameter?

Parameter Trust Requires Fit Quality First

python scripts/run_calibration.py --joint --sample 3
  • A failed quality gate makes covariance a local sensitivity diagnostic—not proof of identifiability
  • Small σ/|value| cannot repair systematic residual mismatch
  • |ρ| ≈ 1, bound hits or near-zero values weaken parameter claims
Report the evidence: fitted values are effective model parameters, not automatically unique material constants.

Task 5 · Defensible claims

Separate Data, Model and Claim

Data

Preserve raw files; state units, illuminated area and sign convention. Experimental efficiency requires independently measured irradiance.

Model

1D abrupt junction, Boltzmann statistics, fixed mobility, coarse Beer–Lambert optics and terminal Rs/Rsh; no band-gap narrowing, texture or lateral grid.

Claim

Fit only sensitive parameters. Show residuals, uncertainty and cross-observable checks; explain systematic mismatch.

Keep the inverse problem identifiable: a transparent two-parameter diagnosis is stronger than an elaborate unsupported fit.
